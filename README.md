# Cambridge Prep

A responsive, self-contained practice prototype for the **Cambridge English B2 First (FCE)** exam.

## Current scope

- B2 First exam preparation.
- Two practice modes:
  - **Exam Simulation** — follows the exam paper order and time limits, with a skippable break timer.
  - **Practice by Section** — choose the exam papers you want to practise.
- Interactive sample task layouts for all four exam components:
  - **Reading & Use of English** — 7 parts and 52 answer fields, with multiple-choice, open cloze, word formation, key word transformations, gapped text and multiple matching formats.
  - **Writing** — two writing tasks with 140–190 word guidance and a live word counter.
  - **Listening** — four part layouts with sample prompts. Audio is not included yet; these are text-only placeholders.
  - **Speaking** — four practice prompt layouts with space to make notes.
- Bottom part navigation, question jump buttons, answer tracking and question bookmarks.
- Cambridge Digital-inspired exam header, timer, pause controls, contrast settings and text-size settings.
- All in-app interface text is in English.

## Important notes

The exercise texts and prompts are illustrative prototype content, not official Cambridge exam questions. The Listening section does not contain audio yet. Answers can be entered and tracked in the current session, but are not saved to an account or database. Automatic marking and Writing/Speaking assessment are not implemented.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.
