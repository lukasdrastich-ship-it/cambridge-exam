# Cambridge Prep

A responsive navigation prototype for preparing for the **Cambridge English B2 First (FCE)** and **C1 Advanced (CAE)** exams.

## Current scope

- Exam level selection: B2 First or C1 Advanced.
- Two practice modes:
  - **Exam Simulation** — follows the exam order and time limits, with a break timer you can skip.
  - **Practice by Section** — choose the exam papers you want to practise.
- Setup summary and back navigation.
- Responsive interface. All in-app interface text is in English.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Not implemented yet

This prototype does not include test questions, saved progress, authentication, or Writing/Speaking assessment.
