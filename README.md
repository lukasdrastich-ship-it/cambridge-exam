# Cambridge Prep

A responsive navigation prototype for preparing for the **Cambridge English B2 First (FCE)** and **C1 Advanced (CAE)** exams.

## Current scope

- Exam level selection: B2 First or C1 Advanced.
- Three practice modes:
  - **Exam Simulation** — follows the exam order and time limits, with an option to skip scheduled breaks.
  - **Flexible Practice** — designed for self-paced practice, breaks at any time (including during a section), and resuming later.
  - **Practice by Section** — choose Reading, Use of English, Writing, Listening or Speaking.
- Setup summary and back navigation.
- Responsive interface. All in-app interface text is in English.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Not implemented yet

This prototype does not include test questions, a working timer, saved progress, authentication, or Writing/Speaking assessment. Break and save/resume flows are planned for a later phase.
